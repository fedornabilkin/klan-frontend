# Требования к интерфейсу Klan

Закрытый портал сообщества. Гость видит вход через Telegram; внутренние маршруты требуют сессии. Доступ к административным действиям отражает права, возвращённые сервером. Демонстрационный вход существует только в локальном режиме API.

## Общие сценарии

Списки имеют поиск, сортировку, фильтры и классическую пагинацию; параметры восстанавливаются из URL при переходах назад и вперёд. Навигация, хлебные крошки, состояния загрузки и ошибок единообразны. Ошибка одного блока не блокирует другие. WebSocket обновляет затронутые данные без дублирования подписок.

Интерфейс адаптируется к мобильным экранам, поддерживает клавиатуру и уменьшенную анимацию. Предпочтительны rem; пиксели допустимы для границ и технических размеров. Палитра тёмная, с оранжевым акцентом.

## Разделы

| Раздел | Поведение |
| --- | --- |
| Главная | Карта участников с начальным фокусом на центральной России, поиск людей и городов, популярные общие теги и поиск полного справочника, активные команды и события. |
| Участники | Список и адрес профиля по публичному ID; данные профиля, теги, факты и достижения от первого лица; кликабельные ссылки. |
| Свой профиль | Редактирование ФИО, позывного, Telegram username и даты рождения одной формой на странице; редактирование описания, местоположения, датированных фактов и достижений в их блоках. |
| Теги | Поиск существующих тегов; создание нового при отсутствии подходящего с подсказкой «одно слово»; открепление своих тегов. |
| География профиля | Страна и город с поиском, города зависят от страны; возможность указать отсутствующий город. |
| Команды | Список и карточки; текущая активная команда возле позывного и блок команды в профиле с числом участников и описанием. |
| Челленджи | Личный и командный зачёт, результаты по датам, фильтры участников/команд/дат и пагинация; результаты с неуточнённой датой отдельно от итогов. |
| Мероприятия | Список, подробности, онлайн/офлайн, даты, состав участников и вещи из общего справочника. |
| Новости, правила, книги | Списки и страницы материалов, отметка о прочитанной книге и список читателей. |
| Обратная связь | Предложения и заявки, карточки и статусы обработки. |
| Аналитика | Статистика сообщества и участников, география, интересы, команды и участие. |
| Управление | Доступные по роли операции над сущностями и справочниками. |

## Проверка изменений

Проверяйте затронутые сценарии с данными API и граничные состояния: пустые списки, ошибки, отсутствие прав, явный ноль и неизвестные даты. Для адаптивности используйте ширины 360, 390, 768 и 1280 CSS px. Реальную авторизацию Telegram проверяют совместно с настроенным API и ботом; успешная локальная демонстрация её не подтверждает.
