# Работа над Klan Frontend

Это самостоятельный репозиторий интерфейса. Команды запуска, проверки и сборки находятся в README.md и выполняются из этой директории.

- Следуйте `docs/architecture.md`, `docs/requirements.md` и `docs/conventions.md`.
- Не добавляйте файловые зависимости на соседние backend, bot или служебные каталоги. API связывает компоненты во время работы; `src/shared` хранит локальную версию контрактов.
- Сохраняйте текущую модель доступа: интерфейс показывает доступные действия, но решение принимает API. Не переносите Telegram-токены, ключи или параметры базы в клиент.
- При изменении поведения выполняйте относящиеся к нему тесты и `npm run build`. Проверяйте затронутые экраны в браузере, если он доступен.
- Модульные тесты, Dockerfile, Compose, настройки веб-сервера, инструкции и сценарии развёртывания принадлежат этому репозиторию. Сборка и запуск не должны читать файлы из соседних каталогов. Разовые отчёты, скриншоты проверок, дампы и реальные данные храните вне Git.
- Не меняйте реальные данные ради проверки интерфейса. Не коммитьте `.env*` кроме `.env.example`, `node_modules`, `dist` и данные участников.
