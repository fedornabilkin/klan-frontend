# Klan Frontend

Самостоятельный интерфейс закрытого сообщества Klan. Стек: Vue 3, TypeScript, Vite, Pinia, Pug, Naive UI и D3. Репозиторий собирается без соседних каталогов backend, bot или общего workspace.

## Запуск

Нужны Node.js 22.12+ и npm. Команды выполняются из этой директории:

```sh
npm ci
npm run dev
```

Адрес: `http://localhost:5173`. API должен быть запущен отдельно на `http://127.0.0.1:3001`. Для другого адреса API скопируйте `.env.example` в `.env.local` и измените `VITE_API_TARGET`; `VITE_DEV_PORT` задаёт порт фронтенда. Vite завершится с ошибкой, если выбранный порт уже занят. В бэкенде `APP_ORIGIN` должен совпадать с адресом браузера. Переменные `VITE_*` считаются публичными: секреты в них хранить нельзя.

```sh
npm run typecheck
npm test
npm run build
```

Сборка создаётся в `dist/`. При размещении веб-сервер направляет `/api` и `/ws` в бэкенд на том же origin, а остальные маршруты обслуживает через `index.html`. Служебные сценарии размещения, локального запуска всех сервисов и разовых проверок находятся вне репозитория.

## Структура

- `src/components` — общие элементы и компоненты функций.
- `src/pages`, `src/layouts`, `src/router` — страницы, каркас и навигация.
- `src/services` — HTTP, WebSocket и прикладные запросы.
- `src/domain` — builders, преобразования и вычисления для интерфейса; рядом лежат модульные тесты.
- `src/stores`, `src/composables` — состояние и повторно используемые сценарии.
- `src/shared` — локальная версия DTO и общих правил представления API. Импортов исходников из других репозиториев нет.
- `docs` — архитектура, требования и соглашения фронтенда.

Бэкенд остаётся источником правил доступа и допустимых изменений. Изменения API нужно согласовывать с backend и обновлять соответствующие типы `src/shared`; копирование этого каталога при запуске не требуется. Реальные анкеты, экспорты, резервные копии, секреты и результаты ручных проверок в репозитории не хранятся.

См. [архитектуру](docs/architecture.md), [требования к интерфейсу](docs/requirements.md) и [соглашения](docs/conventions.md).
