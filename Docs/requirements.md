# Требования к интерфейсу Klan

Закрытый портал сообщества. Гость видит вход через Telegram; внутренние маршруты требуют сессии. Доступ к административным действиям отражает права, возвращённые сервером. Демонстрационный вход существует только в локальном режиме API.

## Общие сценарии

В разделе «Управление → Постоянный доступ» администратор может найти участника и предоставить ему постоянные административные права. Группы и каналы добавляются по публичной ссылке, имени или числовому ID. Изменения вступают в силу после сохранения. При удалении последнего сообщества проверка членства остаётся включённой до явного выбора открытого входа.

Текстовый поиск применяется от трёх символов, фильтры обновляются через 300 мс после последнего изменения. Списки имеют поиск, сортировку, фильтры и классическую пагинацию; параметры восстанавливаются из URL при переходах назад и вперёд. Навигация, хлебные крошки, состояния загрузки и ошибок единообразны. Ошибка одного блока не блокирует другие. WebSocket обновляет затронутые данные без дублирования подписок.

Детальные страницы используют общий компактный заголовок. Хлебные крошки показывают название открытой записи и дают вернуться в список, в том числе на телефоне. В шапке виден счётчик участников онлайн. Нажатие открывает список со ссылками на профили. На узком экране за первым блоком подробностей следуют действия и сведения о записи.

Интерфейс адаптируется к мобильным экранам, поддерживает клавиатуру и уменьшенную анимацию. Предпочтительны rem; пиксели допустимы для границ и технических размеров. Палитра тёмная, с оранжевым акцентом.

## Разделы

| Раздел | Поведение |
| --- | --- |
| Главная | Карта участников с начальным фокусом на центральной России, поиск людей и городов, популярные общие теги и поиск полного справочника, активные команды и события. |
| Участники | Поиск, выбор тегов по названию в адресе и четыре переключателя, как на главной. На странице до 21 карточки с числом тегов каждого участника. Профиль открывается по публичному ID и содержит теги, факты, достижения и кликабельные ссылки. |
| Свой профиль | В одной форме участник редактирует ФИО, позывной, Telegram username, дату рождения и дату вступления в Клан. Дата вступления видна после заполнения. Описание, местоположение, датированные факты и достижения редактируются в своих блоках. |
| Теги | Поиск существующих тегов; создание нового при отсутствии подходящего с подсказкой «одно слово»; открепление своих тегов. |
| География профиля | Страна и город с поиском, города зависят от страны; возможность указать отсутствующий город. |
| Команды | Компактные карточки отсортированы по названию. В составе первыми идут капитан и заместители. Администратор назначает и снимает роли кнопками с галстуком и шпионом, крестик исключает участника. Каждое действие требует подтверждения, исключение также требует причины. В блоке «О команде» видны отметка участия и показатели выбранного челленджа. Справа видны результаты и командные цели завершённых челленджей. |
| Челленджи | Личный и командный зачёт, календарная таблица с текстовым поиском участника, фильтром по команде на момент записи, закреплённым участником, прокруткой до сегодняшней даты и пагинацией по людям; результаты с неуточнённой датой отдельно от итогов. |
| Мероприятия | Пустое поле количества мест означает свободную запись. Организатора выбирают из участников Клана или указывают текстом. Автор записи отображается отдельно. После записи открывается выбор вещей тегами с поиском, созданием и удалением. Участник может указать количество и оставить текстовый комментарий, видимый в списке записавшихся. |
| Детальные страницы | Встречи и челленджи показывают статус и даты проведения. У остальных публикаций в заголовке также доступны дата создания и автор публикации, когда эти данные указаны. |
| Новости, правила, книги | Любой участник может добавить книгу со страницы библиотеки, указав автора книги и краткое описание. После сохранения в списке появляется ссылка на запись. В карточке книги доступны отметка о прочтении и список читателей. |
| Обратная связь | Предложения и заявки, карточки и статусы обработки. |
| Статистика | Города с одним участником раскрываются по нажатию. У челленджей видны первые три места в командном и личном зачётах. Текущие и итоговые места подписаны отдельно. |
| Справочники | Страны и города можно искать, добавлять и редактировать. У каждого города есть страна, регион и необязательная пара координат. Изменения доступны в формах выбора места. |
| Аналитика | Статистика сообщества и участников, география, интересы, команды и участие. |
| Управление | Доступные по роли операции над сущностями и справочниками. В редакторе участника доступны позывной и контактный логин Telegram. При изменении логина обязательно указывается причина. Список городов зависит от страны. Координаты выбранного города заполняются из справочника и блокируются, для добавленного вручную города их можно указать самостоятельно. |

## Проверка изменений

Проверяйте затронутые сценарии с данными API и граничные состояния: пустые списки, ошибки, отсутствие прав, явный ноль и неизвестные даты. Для адаптивности используйте ширины 360, 390, 768 и 1280 CSS px. Реальную авторизацию Telegram проверяют совместно с настроенным API и ботом; успешная локальная демонстрация её не подтверждает.
