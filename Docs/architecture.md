# Архитектура фронтенда

Фронтенд — самостоятельное приложение Vue 3. Оно зависит от JSON API и WebSocket Klan, а не от файлов серверного репозитория. Vite обслуживает разработку на `localhost:5173` и проксирует `/api` и `/ws` в API. Production требует такого же общего origin для cookie-сессии.

Исходники и конфигурация приложения находятся в `Project/`. Пути `src/...` ниже считаются относительно этого каталога. Команды npm также выполняются из `Project/`.

## Поток данных

Данные API проходят через DTO и builders из `src/domain`, затем используются сервисами, composables, Pinia и UI. Builders нормализуют внешний формат; компоненты не должны повторять преобразования транспорта. Типы и общие функции, нужные интерфейсу, лежат в `src/shared`. Изменение API требует согласованного обновления локальных контрактов.

`src/services/api.ts` отвечает за запросы, JSON-конверт и нормализацию ошибок. Авторизация использует серверную HttpOnly cookie. Все маршруты, кроме входа, требуют сессии; сервер дополнительно проверяет каждый защищённый запрос. Фронтенд не хранит Telegram bot token и не выдаёт права.

## Ответственность модулей

Страницы собирают сценарии из компонентов. Pinia хранит сессию и разделяемое состояние; локальные формы и раскрытия принадлежат компонентам. Общие компоненты предоставляют однотипные фильтры, пагинацию, состояния загрузки, карточки и формы. Параметры списков сохраняются в URL.

Naive UI обеспечивает базовые взаимодействия и доступность. CSS-токены определяют поверхности, акцентные цвета, отступы и размеры. D3 обслуживает карту и её агрегаты. Подписки, таймеры и обработчики освобождаются при завершении сценария.

Ошибку показывайте рядом с затронутым блоком, оставляя остальную страницу доступной. WebSocket-события инициируют обновление соответствующих данных; они не подменяют подтверждённый ответ сервера.

## Проверки

Модульные тесты лежат рядом с доменными вычислениями и запускаются через `npm test`. `npm run build` проверяет TypeScript и собирает `dist`. Отчёты ручных проверок и скриншоты не входят в Git. Все файлы сборки и развёртывания находятся в этом репозитории: Dockerfile и Compose — в `Docker/`, конфигурация веб-сервера и systemd — в `Deploy/`, локальные сценарии — в `Scripts/`, инструкция — в [deployment.md](deployment.md). Сборка находится в `Project/dist/`.
